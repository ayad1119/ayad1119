Opdracht 3a

We hebben hieronder een input-veld en een send-button.

Als op de send-button geklikt wordt en het input-veld is leeg, dan wordt een rode rand op het in put veld getoond.

Is het input veld wel gevuld, dan wordt een groene rand op het input veld getoond.

Je kunt een rode of groene rand op het input-veld tonen door in JavaScript class “red” of “green” toe te voegen met classList.

Wat moet het bevatten?

  • DOM (querySelector, addEventListener…)
  • classList
